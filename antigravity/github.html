Connect GitHub

Connect the official GitHub MCP server to the CLI. This connection will appear as ha-github in MCP tools, not in the plugin marketplace.

  1. Create a fine-grained personal access token in GitHub.
  2. Choose the repository owner, a suitable expiry, and Only select repositories. Select the projects this CLI may publish to.
  3. Under Repository permissions, set Contents: Read and write. Metadata read access is automatic. Do not grant Actions or Workflows permissions. Complete any required organization approval.
  4. Paste the token below. Never paste it into the conversation or terminal.
Default publishing: run local checks, publish authorized changes to main, bump the app version when needed, and use no Actions workflows. Existing repository rules and CLI review restrictions still apply.

The token is stored privately in the add-on’s CLI configuration. It is excluded from worker access and status responses. Home Assistant backups may contain it; protect those backups.

After connecting, restart the add-on and open a fresh CLI conversation. Verification reads your account and available tools; it does not create a commit or prove write access to every repository.
