Connection help & deletion

The add-on connects to the local CLI automatically at startup. No message or hook is required. If connection setup fails, restart the add-on and share the connection status and CLI version. This page refreshes automatically while visible.

Only idle conversations can be deleted. Each deletion requires confirmation and cannot be undone here. This list includes locally saved CLI conversations, grouped by project. Archived conversations appear separately. Missing project names use their project ID; unavailable archive metadata is labelled. The selected conversation refreshes before confirmation and immediately before deletion. If it changes, review and confirm the updated entry. The CLI handles deletion and associated cleanup.

Delete conversation?

This removes the conversation and may clean up its associated data. There is no undo.
