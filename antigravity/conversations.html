Terminal

Delete opens the live CLI controls below. Use its conversation picker and confirmation while the CLI stays running.

Offline deletion has been retired. Existing Undo backups remain available with the CLI stopped; new native deletions do not create an add-on Undo backup.

Deleted conversations / Undo

Delete through Antigravity

  1. At an empty CLI prompt, tap Insert /resume, then Enter. If the picker is already open, skip this.
  2. With the picker search empty, tap Paste conversation ID. Check that the matching conversation is selected.
  3. Tap F4 Delete. Read Antigravity's confirmation and press Enter only if it names the correct conversation. Esc cancels.
