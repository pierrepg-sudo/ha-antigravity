Connect after a CLI restart

Ask Antigravity: Run /usr/local/bin/antigravity-connect using your terminal tool. Then tap Refresh. This checks read-only access and keeps the connection credentials private to the add-on.

Use a disposable conversation for the first deletion test. This internal API can change between CLI versions.

Delete conversation?

Antigravity will delete this exact conversation and may clean up associated conversation data. There is no add-on Undo.
